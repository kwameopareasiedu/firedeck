# Firedeck CLI

![](https://firedeck.opare.dev/firedeck-ascii-bg.png)

An opinionated, batteries-included application compiler for Firebase-backed React SPAs.

---

Firedeck compiles your project modules into a fully managed Turbo runtime that you can run, build and deploy to Firebase, using existing tools you already know and love.

[_**Read the docs to learn more**_](https://firedeck.opare.dev).
